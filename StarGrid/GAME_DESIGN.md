# StarGrid · 星星方格

## 项目定位
竖屏、单人、低美术量的规则解谜游戏。通过六种柔和色块和星星构成核心画面，无角色、剧情或复杂场景。目标是让玩家在轻松的节奏里通过排除与推理完成棋盘。当前交付为一个高完成度网页关卡；Unity 正式项目尚未创建。

## 核心循环
阅读规则 → 观察区域 → 放置星星或标记 X → 查看实时规则与冲突 → 修正 → 全部规则满足后通关。允许错误落子，不扣血、不限时。X 是辅助笔记，不是必须填满的目标。

## 当前规则
6×6 棋盘，每行、每列、每个颜色区域各恰好一星；任意两星不能水平、垂直或斜向接触。六个区域使用 A–F 字母辅助识别，避免仅依赖颜色。总计六颗星，全部满足即自动弹出完成窗口。

## 交互与反馈
- 默认放星模式：空格或 X 变星；星再点取消。
- 排除模式：空格或星变 X；X 再点取消。桌面右键可直接切换该格 X。
- 键盘 Tab 选择按钮、方向键在棋盘内移动，Enter/空格执行当前模式。
- 撤销恢复完整棋盘及操作、提示计数。重置清空棋盘及计数，但可撤销。
- 提示每次修正一格：优先移除不属于唯一解的星，否则补上一颗正确星，覆盖该位置的 X。提示属于可撤销操作。
- 每次操作更新规则完成数量与红色冲突描边。没有接触仅代表该条规则当前成立，不代表已经通关。
- 完成窗口展示操作与提示数，可关闭欣赏或重新挑战。无虚假的下一关入口。

## 视觉与布局
暖白背景、深绿色文字、低饱和区域色。桌面最大 430px 居中呈手机布局；手机宽度自适应，短屏可自然纵向滚动。棋盘格保持正方形，主要控制按钮至少 42px 高。星星、符号与 CSS 即为全部美术资源，无字体下载及外部素材。支持减少动态效果的系统偏好。

## 内容与边界
本关“星光花园”包含四条完整规则，用来验证玩法而非承担完整教学。当前没有存档、计时、联网、付费、账号、广告或关卡选择，刷新会重新开始。

## 已确定的产品模式
采用“逐步闯关 + 每日挑战”。普通关卡是主体，每日挑战在普通闯关体验稳定后加入；不采用“第一关极易、第二关骤难”的两关制作为主体。

先制作 5 个难度递进的样板关，再扩展首批 20 关：1–3 关用小棋盘与少量规则教操作；4–8 关引入接触限制、颜色区域与 X 排除；9–15 关使用完整的 6×6 规则；16–20 关增加联合推理深度。困难来自可解释的推理，不依赖反复猜测或连续点提示。

后续每日挑战每天提供一道统一题目，允许分享完成结果与提示次数。关卡日期、统一数据分发、存档及分享机制均待实现。当前 Demo 仍只有一个完整规则展示关，不代表 20 关或每日挑战已经完成。

## 验收
直接打开 WebDemo/index.html 可玩；星、取消、X、撤销、重置、提示、实时状态、冲突标记、通关、重玩完整闭环。胜利取决于规则验证而不是和预设答案比较。详见 Docs/TEST_REPORT.md。

## 后续里程碑
1. 确认网页玩法、字体、颜色与手机触控体验，制作 5 个难度递进样板关。
2. 制作通用 solver：验证无解/唯一解/多解，输出推理步骤与难度指标，再扩展首批 20 关。
3. 以纯 C# 规则层迁移 Unity；数据驱动制作教学与第一章。
4. 加入存档、设置、音效与轻量过关动画；真机验证后再加入每日挑战与结果分享。
