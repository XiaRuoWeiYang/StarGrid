# 规则与提示规格 / v2

## BoardState
长度 36 的数组，0=空、1=星。内部索引 row*6+column，从 0 开始；界面行列从 1 开始。本版移除 X 与撤销状态。givens 是不可取消的固定星索引集合，当前用于每日简单题。

| 规则 ID | 冲突 | 完成 |
| --- | --- | --- |
| ONE_STAR_PER_ROW | 任意行星数超过 1 | 每行恰好 1 |
| ONE_STAR_PER_COLUMN | 任意列星数超过 1 | 每列恰好 1 |
| ONE_STAR_PER_REGION | 任意区域星数超过 1 | 每区域恰好 1 |
| NO_TOUCH | 任意两星行距、列距均 ≤1 | 无接触对 |

每对星只统计一次，自身不参与。冲突格是全部违规星的并集。空行是未完成，不是冲突；无星时不接触规则成立。未启用的规则不能产生限制，第一关允许斜线排列。

evaluate(cells, level) 是纯函数，返回 stars、statuses、conflicts、won。胜利要求恰好六星、每条启用规则成立、全部 givens 保留。胜利不依赖 solver 或预设答案。未知规则 ID 抛错，而非默默忽略。

## Solver 的实际范围
solve(level) 枚举每行一个、各列不重复的列排列，再按可选区域/接触限制剪枝，最多检查 720 个排列。answersFor(level) 进一步筛选满足 givens 的解。结果按尺寸、规则、区域缓存。

当前只支持 6×6、必须同时含行列一星的关卡；不是任意规则/尺寸的通用 solver。对超出范围的数据明确报错。后续 Unity 需独立 LevelData 校验并增加可扩展搜索、超时及推理步骤输出。

## 多解提示
suggest(cells, level) 不修改传入棋盘：
1. 查找保留当前全部星星且满足固定线索的解。
2. 若存在，补入其中一个尚未摆放的位置，返回 extend。
3. 若不存在，找与当前星星重合最多的合法解，移除一个不在此解中的非固定星，返回 repair。
4. 已完成或无解返回 null。

一次补星仅代表一种可行方向，不宣称是逻辑必然位置。只有当前组合无法扩展时才清错。每日固定星绝不能由点击、提示或重新开始移除。

## 输入与结算
普通点击切换 0/1；点击固定星只解释线索，点击已完成棋盘不改变状态。每次有效点击或提示加一次操作。重置清零操作与提示、恢复 givens，不删除完成历史。结算由未完成→完成触发一次；关闭结算后保留下一关入口。

验证脚本：Tests/verify.cjs，覆盖全部普通关合法解、多解提示前缀、冲突边界、每日线索、跨日、连通性、损坏存档及提示收敛。
