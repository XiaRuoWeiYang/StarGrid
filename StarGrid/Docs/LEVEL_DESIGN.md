# 关卡与每日挑战 / v2

## 五个普通样板关
所有关卡当前使用 6×6，先通过少量规则而非缩小棋盘教学。region 数据不代表必然启用区域限制。

| 关卡 | 名称 | 启用规则 | 解数 |
| --- | --- | --- | --- |
| path-01 | 第一颗微光 | 每行、每列一星 | 720 |
| path-02 | 留一点距离 | 行、列、不接触 | 90 |
| path-03 | 颜色的约定 | 行、列、区域；允许接触 | 3 |
| path-04 | 寻找平衡 | 行、列、区域、不接触 | 2 |
| path-05 | 星光花园 | 行、列、区域、不接触 | 1 |

第一、二关颜色仅作装饰。第三关专门学习区域，暂不限制接触，文案必须明确；第四关组合规则；第五关收尾。解数不是难度评分，仍需真人试玩评估推理体验。

第五关区域如下，第三关复用此图但规则不同；第四关把第三行第一格由 A 改成 C，保持区域连通且得到两个解。
```text
A A A A A B
A C B B B B
A C C C C C
C C C C C D
C C E E D D
C C E F F F
```
第五关唯一解（从 1 开始）：(1,1)、(2,4)、(3,2)、(4,6)、(5,3)、(6,5)。生产胜利不使用该数组比较。

## 每日双挑战
每日简单“晨间微光”：行列、不接触，给出一颗不能取消的起始星，筛选后仍为多解。每日困难“深夜星图”：六个连通区域和全部四规则，要求唯一解。

日期采用 UTC+8，北京时间 00:00 更新。seed 为 `hash('stargrid-v2:' + YYYY-MM-DD)`。简单题用日期种子选择合法排列与起始线索，装饰色块可变换；由于线索组合有限，简单题未来可能重复。困难题用固定伪随机序列选择合法星图，再正交扩展生成区域，每区至少三格，检查候选解数恰为一。

困难生成最多尝试 1600 次，防止长时间阻塞；超过上限以经过验证的星光花园对称变换兜底，因此不承诺每天永不重复。相同代码版本和日期生成相同题，不依赖网络。后续可改为服务端预生成题库，增加去重和人工难度标定。

2026-09-18：简单题固定索引 18（第 4 行第 1 列），有 18 解；困难题生成成功且为唯一解。31 天样本检查得到 30 种不同困难布局，其中 5 天走兜底；均合法且唯一。

## 数据契约
level 字段：id、size、name、rules、regions、kind；普通关另含 index，每日关另含 day、difficulty，可选 givens。网页数据内嵌 game.js，避免 file:// 下 fetch 限制。版本变更若改变同日期生成规则，需要同步更改 seed 前缀和存档键，避免旧状态错配。
